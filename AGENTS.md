# Правила проекта

- Работать в `d-win`; дополнительные ветки создавать только по запросу.
- `pro-win` догоняет проверенный коммит из `d-win` только через fast-forward. Без отдельных коммитов в `pro-win`, merge-коммитов, squash, rebase, force push и обратных слияний. При расхождении истории остановить продвижение.
- В `d-win` сохранять минимальный CI; перед продвижением выполнять полный прогон. PR допустим для проверок, без кнопок Merge/Squash/Rebase. Рабочую копию оставлять на `d-win`.
- README — только установка клиента и общая инструкция подключения подписки. Документацию держать краткой, не дублировать поведение кода и историю переписки.
