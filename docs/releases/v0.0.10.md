- Ядро Mihomo обновляется отдельно от приложения. В разделе «О программе» доступны проверка, загрузка и возврат предыдущего ядра. О новых стабильных версиях сообщают уведомления в приложении и трее. Новая версия применяется при следующем подключении; при неудачном первом запуске выполняется автоматический откат.
- Добавлено восстановление подключения после сна и смены сети. Клиент сначала проверяет текущий сеанс и маршруты, а при повторных ошибках локального API или адаптера TUN ограниченно перезапускает ядро. Ручное отключение отменяет восстановление.
- Убрано ожидание фоновых проверок при ручном переключении сервера. Проверки автоматических групп выполняются параллельно; работающие соединения сохраняют прежний маршрут, новые используют выбранный сервер.
- В «Инструменты» добавлены отдельные разделы «Геолокация» и «Базы маршрутизации». Геолокация определяет IP и страны маршрутов. GeoIP, GeoSite, Country и ASN обновляются независимо, с проверкой SHA-256 и формата через Mihomo. Новые базы применяются при следующем подключении; доступен возврат предыдущих и встроенных баз.
- Фоновое определение IP и геолокации теперь полностью учитывает настройку сети. При выключенной настройке ручное определение остаётся доступным.
- Для каждой подписки сохраняется одна предыдущая конфигурация в зашифрованном хранилище Windows DPAPI. Кнопка «Предыдущая версия» появляется после обновления с изменением конфигурации. Откат сохраняет локальные правила, текущие квоты и статус доступа; автообновление подписки приостанавливается до успешного ручного обновления.

Обновление сохраняет подписки и настройки. Локальный откат не восстанавливает серверы или пароли, отключённые поставщиком подписки.
