- PRO-подписки поддерживают собственный ключ каждого сервера. При добавлении по HTTPS клиент проверяет подпись ответа и сохраняет публичный ключ вместе с профилем.
- При обновлении подписки проверяется сохранённый ключ. Если ключ изменился или подпись отсутствует либо повреждена, прежняя конфигурация сохраняется.
- Совместимость с ранее доверенными ключами сохранена. Для получения статуса PRO обновите подписку после обновления сервера до версии с автоматической подготовкой ключа.

Серверное исправление подготовки ключа поставляется отдельно через обновление PRO. Обновление клиента само по себе не меняет настройки сервера.
