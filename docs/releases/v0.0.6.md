- Просмотр подписки отделён от её активации: переключение выполняется кнопкой «Сделать активной».
- Добавлена настройка «Подключаться при запуске» для автоматического подключения активной подписки.
- Улучшены отображение активных, замороженных и недоступных маршрутов, проверка задержек и восстановление подключений.
- Начальные параметры подключения учитывают настройки новой подписки; последующие обновления сохраняют ручные изменения.
- Обновлены опции PRO: фильтры протоколов и транспортов, подбор каналов, принятие результата и откат. Подбор требует поддержки API сервером подписки.
- Исправлен автоматический выбор локального порта: учитывается доступность TCP и UDP, в том числе ограничения Windows.
- В переносимой тестовой сборке добавлены две демоподписки и сценарии проверки без сетевого трафика; реальные подписки продолжают работать через Mihomo.
