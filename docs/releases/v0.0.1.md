Первый тестовый выпуск Nodera для Windows 10/11 x64.

### Возможности

- Подключение через Mihomo в режимах TUN и Proxy.
- Несколько подписок, выбор серверов, локальные правила, диагностика и журнал соединений.
- Обновление активной подписки без ручного переподключения: новая конфигурация проверяется, при ошибке выполняется откат. Открытые TCP-туннели продолжают работать; новые соединения используют обновлённые правила.
- Карта известных участков маршрута: Relay, CDN и выход. Резервное разрешение DNS, обработка CNAME и сопоставление входных IP с TCP-соединениями ядра.
- Проверка и установка следующих версий из GitHub Releases с проверкой размера и SHA-256 установщика.

### Установка

Скачайте `Nodera-Setup-0.0.1-x64.exe` из файлов релиза и запустите мастер. Python, Qt, Mihomo и геоданные входят в комплект. Установщик и приложение требуют права администратора.

Настройки и подписки хранятся в `%LOCALAPPDATA%\NoderaClient`; подписки защищены Windows DPAPI текущего пользователя.

### Ограничения первого выпуска

- Карта показывает известные участки и приблизительную геолокацию IP. Скрытый origin за CDN не определяется по публичному DNS; его адрес должен сообщить поставщик подписки.
- Локально подтверждаются TCP-соединения ядра; UDP/QUIC и соединения за удалённым relay этим способом не подтверждаются.
- Установщик пока без подписи Authenticode.
- Установка на чистой Windows и работа TUN требуют дополнительной ручной проверки. Проверка обновления самого приложения требует следующего выпуска.

### Проверки сборки

GitHub Actions выполняет тесты и Ruff перед созданием установщика. Рядом с установщиком находится файл `.sha256` с контрольной суммой.
