- Снижена фоновая нагрузка на процессор. Счётчики и список соединений используют общий снимок Mihomo, когда их нужно обновить одновременно.
- Настройки наблюдения за соединениями перенесены во вкладку «Сеть». Карточки во вкладках «Сеть» и «Журналы» расположены в два столбца.
- В «Настройки → Сеть» можно включить передачу статистики для активной проверенной PRO-подписки, если её сервер принимает отчёты. По умолчанию она выключена. Передаются состояние, счётчики и события без адресов сайтов и имён процессов.
- В «О программе → Обновления» объединены обновления Nodera, ядра Mihomo и баз маршрутизации. Ядро и базы применяются при следующем подключении. Установка новой версии Nodera запускается отдельно.
- Проверка IP и геолокации маршрута выполняется по запросу в «Подключения → IP и маршрут».
- Если Windows блокирует файлы во время установки, установщик подсказывает, где проверить событие в «Безопасности Windows».

Обновление сохраняет подписки и настройки.
