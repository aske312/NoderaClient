- Исправлены лишние перезагрузки конфигурации при фоновой проверке серверов. Заморозка и восстановление отдельного узла больше не сбрасывают DNS и сетевые настройки остальных маршрутов.
- Автоматическое резервирование выполняется ядром Mihomo по правилам подписки. Ошибка проверки одного адреса больше не заменяет сервер блокирующим маршрутом для всего трафика.
- Результаты старых фоновых проверок больше не влияют на новый сеанс или обновлённую конфигурацию подписки.

Обновление сохраняет подписки и настройки.
