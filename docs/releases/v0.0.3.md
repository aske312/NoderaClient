- Новый компактный интерфейс установщика на PySide6 в стиле минималистичных браузерных установщиков, с логотипом и цветами Nodera.
- Автоматический выбор установки, обновления или восстановления по версии, Git-коммиту и состоянию файлов. Для актуальной целой сборки доступно открытие приложения без переустановки.
- При изменении версии или коммита прежний клиент завершается и удаляется; новая сборка устанавливается в тот же каталог с сохранением пользовательских данных и резервной копией.
- Предпросмотр отделён от механизма установки и не содержит его. Оба EXE требуют прав администратора.
- Параметры папки и автозапуска сохраняются по кнопке «Подтвердить»; после завершения остаётся кнопка открытия клиента.
- MIT-лицензия, условия использования и уведомления сторонних компонентов включены в поставку.
- Автозапуск включён при новой установке. Крестик клиента по умолчанию скрывает окно в трей; полный выход доступен в меню трея.
- Убрана маркировка поставщика подписок. Чистая установка не содержит профилей; пользовательские подписки сохраняются.
- Обновления клиента проверяются повторно, если запуск был занят подключением или сеть недоступна. Загрузка выполняется в фоне; установка запускается отдельно и не закрывает клиент до подтверждения пользователя.
- Добавлена блокировка сборки установщика при случайном попадании пользовательских профилей или настроек в поставку.
