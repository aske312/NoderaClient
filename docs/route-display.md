# Карта маршрута

Карта показывает объявленную цепочку Relay/CDN/выход, а не traceroute. Приоритет: ручной маршрут → метаданные → `dialer-proxy` с текущим выбором групп → однозначные указания в имени. Неизвестные участки и порядок не угадываются; `Relay: Москва` определяет только relay.

«Серверы → Проверить IP»: A/AAAA через API ядра; при ошибке, пустом ответе или Fake-IP — резервные DoH-запросы к `1.1.1.1` и `8.8.8.8`, с обходом CNAME (до 8 переходов, без циклов). Используются адрес `server`, Host транспортных настроек и SNI у CDN-маршрутов; Reality SNI не принимается за адрес сервера. Страна/город/ASN — через HTTPS `ipwho.is`, кэш 24 часа. При подключении запросы геосервиса идут через локальный прокси. Автопроверка отключается в настройках.

Для входных адресов DNS-ответы сопоставляются с установленными TCP-соединениями процесса Mihomo. На карте наблюдаемый IP имеет приоритет перед другими DNS-кандидатами; таблица сохраняет все найденные адреса. Подсказки показывают источник подтверждения. UDP/QUIC и соединения CDN за удалённым relay локально не подтверждаются. Геолокация IP/anycast приблизительна и не доказывает физический путь пакетов. Скрытому origin нужен отдельный адрес из метаданных или ручной настройки: публичный DNS CDN его не раскрывает. Приватные IP не отправляются; внешние сервисы получают домены/IP без секретов подписки.

«Диагностика → Проверить сеть» отдельно определяет внешний IP запроса через прокси с учётом правил.

## Метаданные

```yaml
x-nodera:
  routes:
    node-name:
      - {role: relay, country: RU, host: relay.example.com}
      - {role: cdn, country: NL, host: edge.example.com}
      - {role: server, country: DE, host: origin.example.com}
```

Также поддерживается `x-nodera-route` у узла. До 8 участков; страна — ISO alpha-2, пустая строка — неизвестна, `host` необязателен. Метаданные задаёт поставщик подписки.

«Серверы → Маршрут» сохраняет уточнения отдельно для подписки. Они переживают обновления и меняют только отображение.
