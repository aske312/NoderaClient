# Установка и обновления

## Установка

Windows 10/11 x64. Установщик Inno Setup устанавливает полную сборку в Program Files\Nodera, создаёт пункт меню «Пуск», при выборе — ярлык рабочего стола, регистрирует удаление. Python, PySide6/Qt, библиотеки MSVC, Mihomo и геоданные входят в комплект. Клиенту не требуются Python, pip, Git или интернет для установки.

Приложение и установщик требуют права администратора. Отмена UAC завершает запуск. Данные остаются в `%LOCALAPPDATA%\NoderaClient`, защищены DPAPI и не удаляются деинсталлятором. При вводе учётных данных другого администратора Windows запускает приложение в его пользовательском контексте; это отдельный каталог данных и ключ DPAPI.

Сборка: `scripts/build.ps1 -Installer`; Inno Setup 6 должен быть в PATH или стандартной папке. Результат — `dist/installers/Nodera-Setup-<версия>-x64.exe` и файл `.sha256`. Постоянный AppId сохраняет каталог установки при обновлении. Portable-сборки поддерживаются; установщик переводит их на обычную установку, каталог выбирается в мастере.

## Обновление из GitHub

Источник закреплён: публичные стабильные Releases репозитория `aske312/NoderaClient`. Раздел «Приложение» → «Проверить обновления» обращается к `GET /repos/aske312/NoderaClient/releases/latest`. Проверка ручная; автоматических установок нет.

Принимаются только более новые версии `vMAJOR.MINOR.PATCH` (сравнение чисел), без draft/prerelease. Asset: `Nodera-Setup-<версия>-x64.exe`, до 512 МиБ, точный адрес в указанном репозитории и SHA-256 из поля `digest` GitHub API. При отсутствии релиза/asset/digest установка недоступна. Закрытые репозитории без аутентификации не поддерживаются; токен разработчика не встраивается.

«Скачать и установить» загружает файл через текущее подключение, проверяет размер и SHA-256, атомарно сохраняет его в каталоге данных и повторно проверяет перед запуском. Затем открывается мастер установки и клиент корректно завершает работу, восстанавливая системный прокси. Ошибка загрузки/проверки не закрывает приложение. Установщик не перезагружает Windows автоматически; после установки можно запустить Nodera из мастера.

## Выпуск версии

1. Указать версию в `nodera/__init__.py`, сохранить и отправить проверенный код в GitHub.
2. Создать и отправить тег `v<версия>`.
3. Workflow `.github/workflows/release.yml` проверяет совпадение тега и версии, выполняет тесты, собирает установщик и создаёт **черновик** релиза с установщиком и SHA-256.
4. Проверить установку и обновление на чистой Windows 10/11 x64, затем опубликовать черновик. Проверить наличие SHA-256 в asset metadata через API. Ручной `workflow_dispatch` создаёт артефакты, не релиз.

Перед массовым распространением нужны сертификат подписи кода и подпись exe/установщика в CI. SHA-256 проверяет соответствие GitHub-артефакту; он не заменяет Authenticode. Ключи подписи хранятся в секретах CI. Автоустановка и перенос данных между разными пользователями в текущий механизм не входят.

Документация: [GitHub Releases API](https://docs.github.com/en/rest/releases/releases), [Inno Setup: права установки](https://jrsoftware.org/ishelp/topic_setup_privilegesrequired.htm), [Mihomo API](https://wiki.metacubex.one/api/).
