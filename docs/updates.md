# Установка и обновления

`Nodera-Setup.exe` открывает компактное окно Nodera и требует прав администратора. В нём доступны одно основное действие, условия лицензии и настройки папки, автозапуска и ярлыка. Изменения параметров сохраняются только по кнопке «Подтвердить».

Установщик сам определяет действие:

- **Установка:** Nodera на машине не найдена. По умолчанию используется `Program Files\Nodera Client`, автозапуск включён.
- **Обновление:** отличается номер версии или Git-коммит. Установщик завершает клиент, сохраняет пользовательские данные, удаляет прежнюю версию штатным деинсталлятором и устанавливает новую в тот же каталог.
- **Восстановление:** версия и коммит совпадают, но файлы отсутствуют или изменены. Файлы восстанавливаются без удаления пользовательских данных.

Если версия, коммит и файлы совпадают, появляется сообщение об актуальной установленной версии и кнопка «Открыть Nodera». Восстановление можно запустить вручную. Отдельного выбора технических режимов нет.

Перед изменением установки данные сохраняются в `%LOCALAPPDATA%\NoderaClient-install-backups`. Настройки и зашифрованные профили восстанавливаются после операции, в том числе при ошибке. Временные сеансы, журналы и скачанные установщики в эту копию не включаются. Журналы установки находятся в `%LOCALAPPDATA%\NoderaClient-install-logs`. Если запись файлов не завершилась, сообщение указывает причину, журнал и место сохранения данных; установку можно повторить.

Работающий клиент сначала получает запрос на штатное завершение. При необходимости установщик завершает только процессы установленного `Nodera.exe` в текущем сеансе Windows, восстанавливает принадлежащие Nodera настройки системного прокси и затем заменяет файлы. Другие приложения и другие сеансы не завершаются.

Публичный установщик показывает собственный интерфейс на PySide6. Встроенный Inno Setup используется только как скрытый механизм записи и удаления файлов. После успешной операции остаётся кнопка «Открыть Nodera»; самопроизвольного закрытия окна нет.

`Nodera-Setup-Preview.exe` также требует прав администратора, но содержит только интерфейс: встроенного механизма установки в нём нет. Основная кнопка имитирует завершение, не меняя файлы клиента, папку назначения или автозапуск.

Авторский код распространяется по MIT. Кнопка «Принять и установить» подтверждает условия; полный текст доступен по ссылке «Условия». Отказ от гарантий и ограничение ответственности действуют только в пределах применимого права, не ограничивая свободные лицензии компонентов. Лицензии и уведомления входят в поставку; исходный архив Mihomo находится в `_internal/third_party/mihomo`.

Подписок в поставке нет. Их добавляет пользователь; переустановка не создаёт новые профили. Данные хранятся в `%LOCALAPPDATA%\NoderaClient`.

Крестик клиента скрывает окно в трей. Полный выход — «Завершить» в меню трея. При входе в Windows автозапуск открывает клиент в трее; его можно отключить в настройках. После регистрации задания проверяется его состояние.

Обновления проверяются после запуска установленного приложения, затем каждые шесть часов и вручную в разделе «Приложение». Если клиент занят подключением, проверка повторяется через минуту; при ошибке сети — через полчаса. Источник — последний опубликованный стабильный релиз GitHub с большей версией. Локальная сборка и черновик релиза не становятся обновлением до публикации.

Кнопка «Загрузить обновление» скачивает установщик в фоне без остановки подключения и проверяет размер и SHA-256. После загрузки появляется «Установить обновление»; установку можно отложить. Открытие и закрытие установщика не завершают клиент. Только подтверждение установки запускает штатное завершение клиента и замену файлов. Перезапуск клиента необходим для замены его кода; активное подключение восстанавливается при открытии клиента после завершения обновления.

На чистом профиле Windows список подписок пуст и подключение не запускается. При повторной установке на той же учётной записи ранее добавленные пользователем подписки сохраняются; это не подписки из поставки. Сборка установщика прерывается, если в её файлах найдены защищённые профили DPAPI или пользовательские настройки.

Внизу окна показано `v<версия> build:<Git-коммит>`. Имя публичного установщика — `Nodera-Setup.exe`, рядом создаётся `.sha256`. Для обновления версии 0.0.1 нужен ручной запуск нового установщика, поскольку её старый обновлятор ожидает другое имя файла.
