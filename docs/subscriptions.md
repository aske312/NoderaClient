# Подписки Mihomo

Реализация клиента: `nodera/subscription.py`, `core.py`, `controller.py`.

## Подписка

HTTPS GET по ссылке поставщика. Адрес сервера и путь произвольные; пароль панели клиенту не нужен.
В поставке нет подписок и предустановленных поставщиков. Новый пользователь добавляет ссылку самостоятельно. Повторная установка сохраняет ранее добавленные профили из `%LOCALAPPDATA%\NoderaClient`; это не автоматическая загрузка подписки из установщика.

| Заголовок | Значение |
| --- | --- |
| `Accept` | `text/yaml, application/yaml, text/plain` |
| `User-Agent` | `Nodera/<версия> (Windows; Mihomo)` |
| `X-Device-ID` | Постоянный UUID установки |
| `X-Device-Name` | Редакция ОС, например `Windows 11 Pro` |
| `X-Device-OS` | `windows` |
| `X-OS-Version` | Выпуск Windows, например `25H2` |
| `X-Client-Name` | `Nodera` |
| `X-Client-Version` | Версия клиента |
| `X-Core-Name` | `mihomo` |
| `X-Core-Version` | Версия встроенного ядра |

Ответ: Mihomo YAML до 4 МБ с непустым `proxies`; группы, DNS, правила и HTTPS-провайдеры — из подписки. Перенаправления запрещены. Слушатели, API-секрет, пути кэша и включение TUN задаёт клиент; локальные правила добавляются первыми.

`Subscription-Userinfo`: `upload`, `download`, `total`, `expire` — снимок на момент загрузки. Автообновление: 0/1/6/12/24 часа, по умолчанию 6; работает и во время подключения. Ошибка сохраняет профиль, повтор через 15 минут. 403 — срок/лимит/привязка, 404 — неизвестный токен.

Ручное обновление доступно при подключении; в Proxy-режиме загрузка идёт через локальный прокси. Для активной подписки выполняется `mihomo -t`, затем `PUT /configs?force=false`. Процесс, API-секрет, прокси-порт, TUN и диапазон Fake-IP сохраняются. Выбор существующих серверов восстанавливается. Новые соединения используют новые правила; открытые TCP-туннели сохраняются до закрытия. При ошибке API восстанавливаются прежняя конфигурация и подписка на диске; если откат подтвердить не удалось, интерфейс сообщает об этом. Кэш внешних правил защищён DPAPI и сохраняется между сеансами.

## Локальный API

Контроллер: loopback, случайный Bearer-секрет; имя узла кодируется одним URL-сегментом.

- `GET /proxies` — группы и задержки.
- `PUT /proxies/{name}` — выбор существующего участника `Selector`.
- `GET /proxies/{name}/delay` — HTTPS-проверка узла, таймаут 5 секунд.

Автоматические группы сохраняют стратегию подписки. Выбор хранится отдельно у каждой подписки и влияет на новые соединения. Проверка узла не подтверждает работу всех маршрутов.
