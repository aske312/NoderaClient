# Nodera

Клиент для безопасных подключений на Windows 10/11 x64.

[Скачать установщик](https://github.com/aske312/NoderaClient/releases/latest/download/Nodera-Setup.exe)

1. Скачайте и запустите `Nodera-Setup.exe`, подтвердите права администратора.
2. Примите условия и установите приложение. Все необходимые компоненты входят в комплект.
3. После завершения нажмите «Открыть Nodera».

Для подключения получите HTTPS-ссылку на подписку у своего поставщика. Нажмите «+» на главном экране Nodera и вставьте ссылку. Выберите доступный сервер и нажмите кнопку подключения.

Подписки в комплект не входят.
