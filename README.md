# Nodera

Клиент Mihomo для Windows 10/11 x64: TUN, Proxy, подписки и карта маршрутов.

[Скачать установщик](https://github.com/aske312/NoderaClient/releases/latest/download/Nodera-Setup.exe) · [Релизы](https://github.com/aske312/NoderaClient/releases/latest)

1. Установите Nodera и подтвердите запрос Windows. Зависимости входят в комплект.
2. Добавьте ссылку в разделе «Подписки».
3. Выберите TUN или Proxy и подключитесь.

Автозапуск включён по умолчанию при установке; его можно отключить в параметрах установки или в «Настройки → Основное». При входе в Windows Nodera открывается в трее. Крестик скрывает окно в трей, «Завершить» в меню трея закрывает приложение и его компоненты.

Обновления — в разделе «Приложение». Подписки применяются без ручного переподключения. Данные хранятся в `%LOCALAPPDATA%\NoderaClient`.
