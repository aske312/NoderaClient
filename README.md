# Nodera

Клиент для безопасных подключений на Windows 10/11 x64.

[Скачать установщик](https://github.com/aske312/NoderaClient/releases/latest/download/Nodera-Setup.exe)

1. Скачайте и запустите `Nodera-Setup.exe`, подтвердите права администратора.
2. Примите условия и установите приложение. Все необходимые компоненты входят в комплект.
3. После завершения нажмите «Открыть Nodera».

Для подключения получите HTTPS-ссылку на подписку у своего поставщика. Нажмите «+» на главном экране Nodera и вставьте ссылку. Выберите доступный сервер и нажмите кнопку подключения.

Подписки в комплект не входят.

Обновления Mihomo доступны отдельно от обновлений приложения в разделе «О программе» → «Ядро Mihomo». Nodera проверяет новые стабильные версии после запуска и каждые 6 часов, уведомляет о доступном обновлении и загружает его по кнопке. Архив проверяется по SHA-256 из официального релиза GitHub.

Новое ядро применяется при следующем подключении; текущее подключение продолжает работать. Если первый запуск новой версии не удался, клиент автоматически возвращается к предыдущему ядру. Кнопка «Вернуть прежнее ядро» позволяет выбрать его вручную. Встроенная версия сохраняется как резервная.

После сна и изменения сети Nodera проверяет текущее подключение и при необходимости повторяет восстановление с увеличением интервала. Перезапуск сеанса выполняется после повторных ошибок локального API или отсутствия адреса TUN; недоступность отдельного сервера сама по себе его не вызывает. Ручное отключение отменяет восстановление.

Фоновые проверки каналов выполняются отдельно от ручного выбора сервера. При переключении открытые соединения сохраняют свой прежний маршрут; новые используют выбранный сервер.

В «Инструментах» доступны два отдельных раздела: «Геолокация» определяет IP и страны маршрутов, а «Базы маршрутизации» обновляет GeoIP, GeoSite, Country и ASN с проверкой SHA-256 и совместимости с Mihomo. Новые базы применяются при следующем подключении; предыдущие и встроенные базы доступны для возврата. Наличие обновлений проверяется после запуска и раз в сутки, загрузка запускается кнопкой. Фоновое определение IP и геолокации можно выключить в настройках сети; ручное определение остаётся доступным.

При изменении конфигурации подписки клиент сохраняет одну предыдущую версию в зашифрованном хранилище. Кнопка «Предыдущая версия» в карточке подписки восстанавливает конфигурацию, сохраняя локальные правила, текущие квоты и статус доступа. После отката автообновление этой подписки приостановлено; ручное обновление возобновляет его. Откат не возвращает отключённые поставщиком серверы или пароли.
