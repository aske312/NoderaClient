# Nodera

Клиент для подключения по подписке Mihomo на Windows.

## Требования

- Windows 10 или 11, x64. Для установки нужны права администратора.
- Ориентир для обычного использования — 2 ядра процессора и 4 ГБ оперативной памяти.
- Приложение занимает около 225 МБ. Для установки и обновлений желательно иметь 1 ГБ свободного места.

## Установка и подключение

1. Скачайте [Nodera-Setup.exe](https://github.com/aske312/NoderaClient/releases/latest/download/Nodera-Setup.exe), запустите установщик и следуйте его указаниям.
2. Откройте Nodera. Нажмите «+» на главном экране и вставьте HTTPS-ссылку на подписку от своего поставщика.
3. Выберите сервер в разделе «Подключения» и нажмите кнопку подключения на главном экране. Режим TUN (VPN) или Proxy можно выбрать в «Настройки → Приложение».

Если Windows блокирует установку, проверьте «Безопасность Windows → Журнал защиты» и сверьте SHA-256 файла со значением в [официальном релизе](https://github.com/aske312/NoderaClient/releases/latest).

## Обновление

Откройте «О программе → Обновления» и нажмите «Обновить». Для новой версии клиента после загрузки выберите «Установить Nodera». Ядро Mihomo и базы маршрутизации обновятся при следующем подключении.
